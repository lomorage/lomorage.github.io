Help your memories feel at home

Lomorage keeps your family photo library on hardware you control. Start with the path that sounds most like your home; you can explore the technical options later.

The easiest way to begin

Use a Windows PC or Mac that already has room for your photos. Install the Lomorage photo assistant, add LomoMobile to your phone, then try a small backup and open a few files before moving your whole library.

  • Set up Windows
  • Set up macOS
  • Get the phone app

Already have home storage?

Lomorage also runs on a Synology NAS, Raspberry Pi, Linux server, Docker or Unraid. These guides assume you are comfortable managing that device.

  • See every computer and server option
  • Import photos from an existing drive

After your first backup

Check the backup status, open several originals on the storage device, and keep another independent copy of irreplaceable photos. A local hard drive can fail just like any other drive.
