Product direction

Lomorage is moving toward a calmer way to care for a growing family photo library: help people find clutter, make careful choices, and keep what matters safe on storage they control.

Plans change as the apps and server evolve. For current behavior, rely on these guides and release notes in the Lomorage GitHub repositories. Ideas and unfinished work should not be treated as promised features or dates.
