Choose a computer or home server

The device you choose stores the original photos and should have enough free space for your growing library.

Familiar computers

Windows and macOS are the simplest choices. They are a good fit when you want to try Lomorage with hardware you already know.

Always-on home storage

Use an existing Synology NAS, Unraid or Docker server if you are comfortable maintaining it.

Linux and small home servers

The Lomorage backend is published for Linux amd64, arm64, and armhf, covering common x86_64 computers, 64-bit ARM devices, and 32-bit ARM devices. Guides are available for Raspberry Pi, Armbian, Ubuntu, Fedora, Rocky Linux 9, openSUSE Leap and OpenWrt.

Your originals remain ordinary files on disk. Whichever setup you choose, keep another independent copy of irreplaceable photos.
