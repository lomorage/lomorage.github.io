Build a Low-Power Raspberry Pi Photo Backup Server for Your Family

2026-11-25 #Raspberry Pi #photo backup #self-hosted #Lomorage

A Raspberry Pi sips a few watts, stays on all year, and costs less than a year of many cloud photo plans. Add a USB hard drive and you have an always-on photo backup server that every phone in the house can use. Here's how to build one with Lomorage.

Why a Raspberry Pi

  • Always on, low power. Phones can back up at night without a PC running.
  • Cheap. A board, power supply, microSD card and a hard drive you may already own.
  • Quiet and small. It can sit next to your router.
  • Your files, your drive. Photos are stored as ordinary files in folders by date.

Shopping list

  • Raspberry Pi — tested models include Pi 4 Model B, 3 Model B+, Zero W and 2 Model B. Newer is faster.
  • Official or quality power supply. Under-powering causes strange problems.
  • 16 GB+ microSD card.
  • USB hard drive with room to grow.
  • Powered USB hub — strongly recommended for 2.5" drives or more than one drive.
  • Ethernet cable — faster and more reliable than Wi-Fi.

Install in four steps

  1. Download the prebuilt Lomorage image linked in the Raspberry Pi guide.
  2. Flash it to the microSD card with balenaEtcher.
  3. Connect the hard drive, Ethernet and power, then wait a few minutes for the first boot.
  4. Install LomoMobile on your phone, create your account and start backing up.

Prefer to keep your existing Raspberry Pi OS? The guide also covers Docker and apt installation. Using a different board? See Armbian.

Make it reliable

  • Use a powered hub for drives — power issues are the most common cause of disconnects.
  • Add a second drive as a redundancy backup. Step-by-step: Set up a secondary backup with Raspberry Pi.
  • Know your recovery path. If the microSD card fails, your photos are still on the hard drive and the database is backed up there too — see how to recover from a boot failure.
  • Outgrowing the Pi? Move the library to a Windows server and a bigger drive with our migration guide.

Bonus: a photo frame

The prebuilt image includes the Lomorage digital frame application. Plug in an HDMI screen and the Pi can show your family photos — or use an old Android tablet as a frame.

Remote access

To view originals away from home, set up a tunnel or router port mapping: External access.

A Pi server is a great first copy. Keep a second and an off-site copy too — the 3-2-1 rule explains why.
