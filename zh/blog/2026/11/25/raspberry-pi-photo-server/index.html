用树莓派搭建低功耗家庭照片备份服务器

2026-11-25 #树莓派 #照片备份 #私有云 #Lomorage

树莓派只耗几瓦电，可以全年开机，价格比很多云相册一年的费用还低。再接一块 USB 硬盘，就是一台家里每部手机都能用的全天在线照片备份服务器。下面介绍如何用 Lomorage 搭建。

为什么选树莓派

  • 一直在线、低功耗。 手机可以在夜里备份，不用开着电脑。
  • 便宜。 一块主板、电源、microSD 卡，再加一块你可能已经有的硬盘。
  • 安静小巧。 放在路由器旁边就行。
  • 文件在自己硬盘上。 照片以普通文件按日期分文件夹保存。

购买清单

  • 树莓派——已测试型号包括 4B、3B+、Zero W 和 2B，越新越快。
  • 官方或质量可靠的电源。 供电不足会导致各种奇怪问题。
  • 16 GB 以上 microSD 卡。
  • USB 硬盘，留足增长空间。
  • 带电源的 USB 分线器——使用 2.5 寸硬盘或多块硬盘时强烈建议。
  • 网线——比 Wi-Fi 更快更稳定。

四步安装

  1. 下载预装 Lomorage 的系统镜像，链接见树莓派安装指南。
  2. 用 balenaEtcher 烧录到 microSD 卡。
  3. 连接硬盘、网线和电源，等待几分钟完成首次启动。
  4. 在手机上安装 LomoMobile，创建账号，开始备份。

想保留现有的树莓派系统？指南里也介绍了 Docker 和 apt 安装方式。其他开发板可参考 Armbian。

让它稳定运行

  • 硬盘接带电源的分线器——供电问题是掉盘最常见的原因。
  • 再加一块硬盘做冗余备份，详细步骤：树莓派设置冗余备份。
  • 了解恢复方法。 即使 microSD 卡坏了，照片仍在硬盘上，数据库也备份在那里——参见常见问题。
  • 树莓派不够用了？ 用我们的迁移指南把图库搬到 Windows 服务器和更大的硬盘。

额外福利：电子相框

预装镜像包含 Lomorage 电子相框程序。接上 HDMI 屏幕，树莓派就能展示家庭照片——或者把旧安卓平板变成相框。

外网访问

想在外面查看原图，可以配置内网穿透或路由器端口映射：外网访问。
