安装与下载

先准备电脑，再拿起手机。

第一次需要在两台设备上各装一个应用。我们一步步来，让今天的照片，在家里多一份备份。

01

你家里用的是哪种电脑？

电脑负责保存照片。这一步请在电脑上操作，并预留足够的硬盘空间。

选择你的电脑

  1. 打开 PowerShell

    在电脑的“开始”菜单搜索 PowerShell，然后打开。不需要选择“以管理员身份运行”。

  2. 复制下面这条命令，粘贴后按回车

    $env:LOMOD_CHINA=1; irm https://lomorage.com/windows/install.ps1 | iex

  3. 等待安装，然后完成照片存储设置

    安装会下载所需文件并启动 Lomorage。跟着电脑上打开的设置页面完成首次设置；以后可以从“开始”菜单搜索 Lomorage 打开。

适用于 Windows x64 电脑。安装期间需要联网；不必反复粘贴命令。

遇到问题？查看详细帮助 ↗查看安装脚本

  1. 打开“终端”

    按 Command + 空格，搜索“终端”并打开。不需要输入管理员密码。

手机里没有找到电脑，怎么办？+

当前快捷安装默认关闭自动发现。可在手机应用中手动填写电脑的局域网 IP 地址与端口（默认 8000）。确认两台设备在同一网络，且电脑防火墙允许家庭网络访问。手机中不要填写 localhost，它代表手机本身。

你可能还想知道

开始之前，聊清楚几件事。

查看全部常见问题 ↗
是装在手机上，还是电脑上？+

两个都需要。电脑端负责保存原文件，手机应用负责传输和浏览照片。在本页的“安装与下载”区域，先安装电脑端，再获取手机应用。

需要我每天手动操作吗？+

备份需要电脑开机，且手机能够连接到它。手机系统会限制应用在后台的运行；第一次备份或照片较多时，建议打开应用进行备份，并查看是否完成，不把“已经安装”当作“已经备份”。

备份以后，手机里的照片就能删了吗？+

先检查备份状态，打开电脑中的照片和视频确认完整可用，并为重要内容保留另一份独立副本，再考虑清理手机原文件。首次使用时，建议先用少量照片熟悉流程。

如果电脑坏了，照片会不会也丢？+

存在电脑上不等于永远不会丢。硬盘故障或误删除仍可能导致照片丢失。建议定期把重要照片再复制到另一块独立硬盘，并检查这份副本能正常打开。

以后找照片，需要电脑一直开着吗？+

读取保存在电脑里的原文件时，电脑需要开机且网络可达。手机能离线查看哪些内容，取决于应用已缓存的内容；不要假设所有原图都可以离线打开。
