安装 Lomorage

Lomorage 由两部分组成：照片保存设备上的照片助手，以及每部手机上用于备份和浏览照片的 LomoMobile。

1. 选择照片住在哪里

大多数家庭可以从 Windows 或 macOS 开始。如果你已经在使用 NAS 或家庭服务器，可以查看全部服务器平台。

2. 安装手机应用

在 iPhone 与 iPad 或 Android 上安装 LomoMobile。初次设置时，让手机与照片保存设备连接同一个家庭网络。

3. 先试着备份几张

从少量照片开始。确认它们出现在相册中并且能够打开，再备份全部内容。仅仅装好应用，并不代表照片已经完成备份。

电脑或 USB 硬盘里还有旧照片？可以使用照片导入工具。
