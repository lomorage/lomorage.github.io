选择电脑或家庭服务器

你选择的设备负责保存照片原文件，需要为不断增长的相册留出足够空间。

熟悉的电脑

Windows 和 macOS 最容易上手，适合先用家里已有的电脑体验 Lomorage。

长期开机的家庭存储

如果你熟悉设备维护，可以使用已有的 群晖 NAS、Unraid 或 Docker 服务器。

Linux 与小型家庭服务器

Lomorage 后端提供 Linux amd64、arm64 和 armhf 版本，覆盖常见的 x86_64 电脑、64 位 ARM 设备和 32 位 ARM 设备。现有指南包括 树莓派、Armbian、Ubuntu、Fedora、Rocky Linux 9、openSUSE Leap 和 OpenWrt。

照片原文件会继续以普通文件的方式保存在硬盘上。无论选择哪种设备，都建议为无法替代的照片保留另一份独立副本。
