产品方向

Lomorage 正在探索一种更从容的家庭照片整理方式：帮助人们发现杂乱、谨慎做出取舍，并把真正重要的回忆安全地保存在自己掌握的存储设备中。

随着手机应用和服务器持续更新，计划也会调整。当前实际功能请以这些使用指南和 Lomorage GitHub 仓库的发布记录为准；尚未完成的想法不应被理解为已经承诺的功能或日期。
